# Citations and attribution

- Hinton, G. E., and Salakhutdinov, R. R. (2006). “Reducing the Dimensionality of Data with Neural Networks.” *Science*, 313(5786), 504–507. https://doi.org/10.1126/science.1127647. Background reference for neural-network dimensionality reduction and autoencoder-based representations.
- PyTorch contributors. *PyTorch documentation*. https://pytorch.org/docs/stable/. Framework used to define, train, and run the autoencoder.
- NumPy contributors. *NumPy documentation*. https://numpy.org/doc/. Used for numerical operations and synthetic sensor generation.
- pandas development team. *pandas documentation*. https://pandas.pydata.org/docs/. Used to create, validate, and save the tabular sensor dataset.
- scikit-learn developers. *scikit-learn documentation*. https://scikit-learn.org/stable/. Used for feature scaling and evaluation metrics.
- Matplotlib development team. *Matplotlib documentation*. https://matplotlib.org/stable/. Used for training, evaluation, and monitoring plots.
- The industrial sensor readings and anomaly events created by `generate_data.py` are synthetic and were generated for this educational project. They are not measurements from real equipment or an external dataset.
